🔌 How to connect cloud AI — step by step Free, 5–10 minutes: one key for speech recognition and one for text analysis

Viato can run entirely on your computer — then no keys are needed. Cloud AI is faster and more accurate on long calls. Two services are enough for a free start: Cloudflare turns speech into text, Google Gemini turns text into tasks and minutes. Keys are stored only on your computer.

Where keys go: Viato → Settings → “AI processing” → “Providers” → expand the service → paste the key → “Save key”. You’ll see “Key saved”.
STEP 1 · SPEECH → TEXT

Cloudflare Workers AI

free

You need two values: an API token and an Account ID. Both come from the same page.

  1. Sign up at dash.cloudflare.com/sign-up — email and password, no card needed. Confirm your email via the link in the message.
  2. Open the Workers AI page: dash.cloudflare.com → AI → Workers AI. If Cloudflare asks for an account, pick yours.
  3. Click “Use REST API”.
  4. Click “Create a Workers AI API Token” → change nothing → “Create API Token”.
  5. Click “Copy API Token” — this goes into the CLOUDFLARE_API_TOKEN field. Paste it into Viato or save it right away: the full token is shown only once.
  6. On the same page, under “Get Account ID”, copy the Account ID — this goes into the CLOUDFLARE_ACCOUNT_ID field.
  7. In Viato: “Providers” → Cloudflare Workers AI → paste both values → “Save key”.
⚠️ Don’t use the “Global API Key” and don’t create a token from other templates — you need exactly the Workers AI token from this page. The Account ID is 32 characters of digits and letters, not your email.
STEP 2 · TEXT ANALYSIS

Google Gemini

freetrains on your data

One key is enough. Alternatives: Zhipu GLM (free) or DeepSeek (cents).

  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. If a terms of service dialog appears, accept it.
  3. Click “Create API key”. If Google asks for a project, pick any one from the list (usually “Default Gemini Project”).
  4. Copy the key — it starts with AIza.
  5. In Viato: “Providers” → Google Gemini → paste the key → “Save key”.
⚠️ Gemini’s free tier uses requests to improve Google products. For confidential conversations, turn on “Local AI only” in Viato or use a provider that doesn’t train on your data.

Check: dictate “Task for me: check the AI” and open “Recordings” — it shows which model did the work.

Other providers

Connect two or three: if one is down or hits its limit, Viato switches to the next. Paid services work only when “Paid AI services” is on in Viato.

Groq free speech and text
  1. Sign in at console.groq.com (Google or email).
  2. Open console.groq.com/keys → “Create API Key” → enter any name (e.g. Viato) → confirm.
  3. Copy the key (starts with gsk_, shown only once).
  4. In Viato: “Providers” → Groq → paste → “Save key”.
Zhipu GLM (Z.ai) free text
  1. Sign up at z.ai/model-api.
  2. Open the keys page z.ai/manage-apikey/apikey-list and create a new key.
  3. Copy the key. In Viato: “Providers” → Zhipu GLM → paste → “Save key”.

The GLM-4.7-Flash model is free, no top-up needed. It can be overloaded at peak hours.

DeepSeek paid, cents text · best on long calls
  1. Sign up at platform.deepseek.com.
  2. Top up your balance: platform.deepseek.com/top_up. $2–5 lasts a long time.
  3. Open platform.deepseek.com/api_keys → “Create new API key” → copy the key (shown only once).
  4. In Viato: “Providers” → DeepSeek → paste → “Save key” → turn on “Paid AI services”.
Qwen / Alibaba DashScope paid after a free quota text
  1. Sign up at alibabacloud.com.
  2. Open the Model Studio keys page in the Singapore region: Model Studio → API Key. If the console asks you to activate Model Studio, do so. The region in the top right must be Singapore.
  3. “Create API Key” → keep the defaults → “OK” → copy the key right away: it can’t be shown again after you close the dialog.
  4. In Viato: “Providers” → Alibaba Qwen / DashScope → paste → “Save key” → turn on “Paid AI services”.
OpenAI paid text
  1. Sign in at platform.openai.com.
  2. Top up your balance: Settings → Billing. A few dollars last a long time.
  3. Open platform.openai.com/api-keys → “Create new secret key” → copy the key (starts with sk-, shown only once).
  4. In Viato: “Providers” → OpenAI → paste → “Save key” → turn on “Paid AI services”.

🖥️ How to launch a server for your team One admin and 15 minutes: order a server, paste its address and password into Viato, invite people

Step 1. Choose a server

BASIC

No AI on the server

  • 1–2 cores, 2–4 GB RAM, 10–20 GB disk
  • Ubuntu 22.04 / 24.04 or Debian 12 / 13, x86 or ARM CPU
  • Usually a few euros a month

Enough for the team’s tasks, chats and calls. AI runs on people’s computers or in the cloud.

WITH LOCAL AI

AI for the whole team on the server

  • 4+ cores (8 is better), 8+ GB RAM (16 GB is better), 30+ GB disk
  • Same OS: Ubuntu or Debian. No graphics card needed — server AI runs on the CPU

The server transcribes and analyses recordings for everyone: nothing goes to the cloud, laptops stay free. Viato checks the server and suggests a model that fits.

  1. Sign up with any VPS/VDS hosting (for example Hetzner, DigitalOcean, Timeweb Cloud, Selectel) and create a server. Pick a country it’s easily reachable from for everyone.
  2. Operating system: Ubuntu 24.04. Login method: root password (not just an SSH key).
  3. Once the server is created, find its IP address and root password in the hosting panel — they’re often emailed to you.
  4. If the hosting has a firewall or “security groups”, open incoming ports TCP 443 and 22.

Step 2. Get a license key

Message us on Telegram — we’ll give you a Team 5 key right away. Activate it within the period stated when it’s issued.

Step 3. Install the server from the app

  1. Viato → Settings → “Mode and works” → “With a team” → “Add a work” → “Set up the server”.
  2. “Choose the key file” — pick the license file (or paste its text).
  3. Enter the server IP address, root password and company name.
  4. Your name, admin login and password (at least 8 characters).
  5. “Install” — usually 1–5 minutes, with progress shown step by step.
  6. Save the server key it shows somewhere safe.
The root password is used only for setup and is never stored. Right after setup, turn off password login: “Team” → “Server”. The app updates the server with its own key.

Step 4. Turn on backups

  1. “Team” → “Backups” → set a backup password and write it down: without it a file can’t be opened, and it can’t be recovered.
  2. Turn on “Make them automatically”, choose how often and how many copies to keep. The folder can be on a cloud drive or a USB stick.

Step 5. Local AI on the server (optional)

In the company workspace: Settings → “Company AI keys” → install local AI on the server. Viato checks memory and disk and suggests a model. There you can also share cloud keys through the server — with a daily limit per person.

Step 6. Invite people

  1. “Team” → “Invitations” → “New invitation” → copy the code (starts with VIATO1-) and send it to the person in any messenger.
  2. The person: Settings → “Mode and works” → “With a team” → “Add a work” → “Join with a code”, then picks a login and password.
  3. Approve them: “Team” → “People” → “Approve”.
An office server instead of a VPS your own machine, no rent

Any computer or mini PC that stays on will do. Handy when everyone is in the office or connects to it over a company VPN. If people work from different places without a VPN, renting a VPS is simpler.

NO AI ON THE SERVER

2 cores, 4 GB RAM, 20+ GB SSD. An old office PC or an inexpensive mini PC will do.

WITH LOCAL AI

4+ cores (8 is better), 16 GB RAM, 50+ GB SSD. No graphics card needed.

  1. Install Ubuntu Server 24.04. In the installer, tick “Install OpenSSH server”.
  2. In the router settings, give the computer a fixed address on the network (DHCP reservation), e.g. 192.168.1.50.
  3. Allow root password login for the setup — run on the server: 
    sudo passwd root
echo "PermitRootLogin yes" | sudo tee /etc/ssh/sshd_config.d/10-root.conf
sudo systemctl restart ssh
  4. Then follow Steps 2–6 as with a VPS, using the computer’s office network address instead of a hosting IP.
  5. After setup, turn off password login: “Team” → “Server”.

FAQ

Frequently asked questions

Where do my recordings go?

Wherever you decide: only your computer, hybrid mode, or a cloud provider of your choice using your own key. The Viato developer has no cloud — we never see your recordings or tasks.

Do I need the internet?

No. Recording, tasks and lists always work, and with local AI so does all processing. The internet is only needed for cloud models and team sync.

Do I need a powerful computer?

No. Light local models work on an ordinary office laptop, and long calls can go to a free cloud model. With a 4 GB+ graphics card, minutes are produced fully locally.

How much does the AI cost?

Local AI and free cloud models cost nothing. Paid services are off by default and cost cents per call if you turn them on.
